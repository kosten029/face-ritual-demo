# Face Ritual · Demo

[Open the preview](https://kosten029.github.io/face-ritual-demo/)

**MVP 0.6.1 · Exercise Bible Gold v1.1**

A 90-second Morning Reset, gentle guided face techniques and a daily Face Map.
Discover → Feel → Control → Ritual → Your Ritual follows your accumulated practice days.
A day away never resets your journey. Technique cards offer one small reason to return;
the map remembers sessions and active days for the areas you practiced.

This repository contains the compiled web preview. Application source and product documentation are maintained separately in a private repository.

Progress stays in your browser. Four movement demonstrations are available; sixteen are still in preparation. This MVP is a prototype; technique content still requires professional review.

The preview is publicly accessible without a password. Its pages request no indexing by search engines.

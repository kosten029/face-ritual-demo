# Face Ritual · Demo

[Open the preview](https://kosten029.github.io/face-ritual-demo/)

**MVP 0.7.0 · 21 practice days**

A gentle introduction to daily face practice, with 21 guided lessons and five tabs:
Today, Face Map, Practice, Library and Profile. Pauses between sessions never spend
your learning days. Only a completed lesson advances learning, at most once per day.

- 20 technique cards, 16 short explanations and Russian / English interface text.
- A daily Face Map, calendar, personal notes and weekly / monthly summaries.
- Separate voice and background volume controls.
- Basic access after learning, plus a Membership preview; purchases are not connected.

This repository contains only the compiled web preview. Application source,
product documentation and the update presentation are maintained in a private repository.

Progress stays in your browser. Movements are drafts and require professional review;
voice recordings are incomplete. This is a product preview, not the store release.

The preview is publicly accessible without a password. Its pages request no indexing by search engines.
